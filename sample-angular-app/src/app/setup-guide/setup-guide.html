1. Test the visual locally (this app)

  1. In sample-angular-app run npm install, then npm run dev.
  2. Open http://localhost:4200 and paste your Google Maps API key in the header, then press Apply.
  3. Pick any button under Examples. The map reloads with that feature.
  4. Edit the Format objects JSON or upload your own CSV to try your data. Click Reload visual after you change the visual's source.

This app uses a mock Power BI host. Report-page tooltips, bookmarks and real cross-visual filtering only work in Power BI.

2. Get a Google Maps API key

  1. In Google Cloud Console, enable Maps JavaScript API (and Geocoding API if you use addresses) and turn on billing.
  2. Create an API key and use API restrictions. Power BI runs visuals in a sandboxed iframe with no origin, so HTTP-referrer restrictions make Google reject the key. For this test app only, you can add http://localhost:4200/* as a referrer.
  3. Optional: create a Map ID (DEMO_MAP_ID works for testing) for Advanced Markers and cloud styling.

The key is stored inside the report, so anyone who can edit the report can read it. Use a dedicated key with quotas.

4. Use it in a Power BI report

Power BI Desktop

  1. File → Options and settings → Options → Current file → Report settings, tick Developer mode for this session.
  2. In Visualizations, click … → Import a visual from a file and choose the .pbiviz.
  3. Add the Google Maps icon to the page and size it.
  4. Format visual → Map → Google Maps API key: paste your key.
  5. Drag fields into the wells: Latitude and Longitude (set to Don't summarize), Legend, Size, Color saturation, Path ID + Path order for lines, or Geometry for shapes. The Examples menu in this app shows which roles each feature needs.

Power BI Service

  1. Open the report, click Edit, then … → Import a visual from a file. This needs the tenant setting Allow visuals created using the Power BI SDK.
  2. Or, for teams: an admin uploads the file once under Admin portal → Organizational visuals, so it appears for everyone.
  3. Click Publish in Desktop to share the report.

5. Use it in your own application

Your app embeds a Power BI report that contains the visual, using Power BI Embedded. The visual itself is not an Angular component.

Prerequisites

  • The report from step 4 is published to a workspace on Fabric/Power BI capacity (an F, P or A SKU).
  • An Azure AD app registration (service principal) that is allowed to use Power BI APIs and is a member of that workspace.
  • The visual is saved inside the report. Importing it into the .pbix (step 4, Desktop) is the simplest route. Check Microsoft's embedding documentation before relying on organizational visuals in an embed.
